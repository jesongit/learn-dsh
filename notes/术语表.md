# 术语表

> 从第 0 章起持续维护：中英对照 + 一句话解释。可对照 `deepseek-harness/docs/glossary.zh.md` 扩充。

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| harness | harness | 围绕模型的一切外围系统（循环、工具、上下文、持久化、UI），把模型变成能干活的 agent |
| agent loop | agent loop | 「请求模型 → 执行工具 → 结果回填 → 再请求」的驱动循环，agent 的心脏 |
| 会话 | session | 一次连续协作的容器，以只追加的事件日志形式存在，是单一事实来源 |
| 轮次 | turn | 从领到一条输入到「模型不再欠工作」的完整过程，含 1..n 个 step |
| 步骤 | step | 一次模型请求 + 它调用的全部工具 |
| 转向/中途插话 | steering | 用户在 agent 工作中途插入新输入，影响其后续行为 |
| 上下文 | ctx (context) | Cordis 的服务容器；也泛指送给模型的消息历史 |
| 插件 | plugin | 向共享上下文贡献服务、事件和副作用的单元，dsh 中一切皆插件 |
| 服务 | service | 挂在 ctx 上的能力（如 ctx.tools），消费者按 key 查找而非 import 实现 |
| 接缝 | seam | 可替换能力的三件套：接口定义 + 提供方 + 消费方；换提供方即换能力 |
| 瀑布事件 | waterfall event | 环绕式（洋葱模型）事件，监听器可包装或短路下游，dsh 的主要扩展手法 |
| 适配器 | (LLM) adapter | 把具体模型 API 翻译成统一消息/流式词汇的 seam 实现 |
| 工具 | tool | 模型可调用的能力，以 JSON Schema 描述，经执行管线运行 |
| 压缩 | compaction | 上下文超限时把旧内容摘要/裁剪，保持对话可持续 |
| 子代理 | subagent | 被主 agent 派生出来执行子任务的独立 agent 实例 |
| 沙箱 | sandbox | 限制工具执行所启动进程的权限边界 |
| 组合包 | bundle | 插件配置的分发/装配格式，profile 由有序 bundle 叠加而成 |
| 品牌化类型 | branded type | TS 手法：用类型系统区分同结构但语义不同的 ID（如 CallId ≠ SessionId） |
| 模拟适配器 | mock adapter | 实现同一接口的测试替身（stub）：按预注册响应序列回放，用于确定性测试 |
